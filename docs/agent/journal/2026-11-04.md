## Decisions
- ADR 0010: `--select`, `--ignore`, `--fail-on` replace the file's values (no
  `--extend-*` flags yet); one configuration per run, discovered from the working
  directory. Config and selector errors are snippets of the file
  (`HumanRenderer::render_error`), exit code 2; a bad selector in a flag is a one-line
  error.
- ADR 0011: `exclude` globs are relative to the config file's directory, `*` does not
  cross `/`, a pattern matching a directory excludes everything below it, and named files
  are excluded too (pre-commit). Excluded files are not counted as "skipped".
- M2-04 split into M2-04a (suppressions) and M2-04b (KL0003, allocated in the catalog).
  Suppressions: the directive must open the comment, `next-line` skips comment-only
  lines, KL0001 cannot be suppressed, any built-in rule can be named (codes and names
  only, not categories).
- KL0003 is engine-reported like KL0001, but selectable and suppressible like any rule.
- ADR 0012: `kubelint rules --format json` is a plain array of
  `{code, name, category, default_enabled, default_severity, summary}`; `kubelint rule`
  prints Markdown that M3-01 can reuse.

## Problems
- Inline `insta` snapshots still cannot be filled without `cargo-insta`: wrote `@""`
  placeholders, which failed; switched to file snapshots.
- A settings test hard-coded the default rule list and broke when KL0003 landed; it now
  derives the list from the registry. Avoid hard-coding the rule list in tests.
- `git push --force-with-lease` fails with "stale info" when the remote session branch
  was deleted after a merge; plain `git push -u` works (already noted on 2026-11-01).
