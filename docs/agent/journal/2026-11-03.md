## Decisions
- Helm: a directory with `Chart.yaml` is a chart; its `templates/` (any depth) and its
  `Chart.yaml` are skipped, even when named on the command line (pre-commit passes file
  names). `values.yaml` and `crds/` are still linted. One note on stderr for all charts;
  the summary line adds `, skipped N files`. `Chart.yaml` is skipped because its
  `apiVersion: v2` would otherwise trigger KL1002.
- KL0002 compares keys by unquoted text, skips `<<` merge keys and non-scalar keys,
  de-duplicates findings repeated by aliases, and checks Kubernetes objects only.
- ADR 0009: categories and code prefixes select only rules enabled by default; codes and
  names select any rule; `ignore` wins; KL0001 cannot be ignored or re-leveled; unknown
  selectors are errors carrying their list and index; severity overrides take one rule.
- M2-03 split into M2-03a (config crate, done), M2-03b (CLI wiring) and M2-03c (exclude).
- `kubelint_config` has its own `Level` enum and `Spanned<T>` type, because it may only
  depend on `kubelint_source`. `[lint.severity]` comes back sorted by key.
